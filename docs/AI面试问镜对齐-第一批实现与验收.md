# 问镜功能对齐：第一批实现与验收

日期：2026-10-12。对应开发规格 v0.2；本记录不代表完整问镜功能已经对齐。

> 本文记录的是旧第一批实现，后续已由问镜移植版本替换。当前数据来源、Redis 和构建验收见 [2026-10-13 文字面试补齐与验收](问镜文字面试补齐与验收.md)；本轮按用户确认不接原刷题题库。

## 本批业务代码

- 替换原模拟面试设置页为“方向 → 你是谁 → 目标岗位”。复用问镜固定版本的 15 个方向及岗位模板目录，保留面试蛙主题。
- Java 提供目录、解析任务受理及查询接口，通过已有 Nacos/OpenFeign 调用 Python。所有任务归属来自服务端登录态。
- Python 新建 `interview_setup_jobs` 表，异步解析简历与 JD。支持 PDF、DOCX（含表格）、TXT、MD 和粘贴文字，文件最多 5 MiB；无 OCR 时明确提示。
- 解析后可以编辑个人概述、技能、项目、职责、贡献、难点、岗位要求及维度。前端按用户保存设置草稿；原始文件不保存到浏览器。
- v2 创建冻结确认后的设置。先自我介绍，模型整理画像；自我介绍不套技术题参考答案评分。
- 新面试图结合画像、岗位、考察维度和历史安排问题，显示真实项目关联。知识候选从 Java 提供的题库快照经 ES BM25＋真实向量召回筛选，不再固定按 ID 顺序出正式题。
- 发布问题时生成并冻结必答点和最低要求。模型生成的合同标记为 `model-draft`，不冒充人工审核标准；题库参考答案仅存私有合同。
- 评价保存合同覆盖、回答意图、维度分和原文引用。规则验证引用与覆盖集合，失败明确可见；重试错误引用会重新评价原答案。
- 支持每题最多两次提示及受限多轮追问。自我介绍独立计数，主问题和追问都占正式轮次，短/标准/深度目标分别为 5/8/12。
- 新增独立报告页、未覆盖维度展示、模型总结与训练任务，训练任务链接到对应作答回放。
- 旧 v1 检查点继续路由到原图；不把历史检查点直接交给新拓扑。

## 验收依据

Python 回归及真实 MySQL/ES 集成共 80 项通过（真实集成使用独立一次性测试库，恢复子进程配置 PYTHONPATH 与 UTF-8 输出）；Java 相关契约 11 项通过并打包成功。新增/修改前端文件的定向 TypeScript 检查与 lint 通过。项目其他既有 TypeScript 错误仍存在，本批不声称全局类型检查或生产构建通过。

真实链路：Java → Nacos/OpenFeign → Python → LangGraph/MySQL → DeepSeek。使用普通临时账号与合成资料，验证目录、简历和 JD 解析、自我介绍、提示、评价、跳过、结束、报告、训练及重复命令。合成评分仅证明链路和结构有效，不是准确率评测。

浏览器验证三步设置、画像回填和编辑、岗位模板及 JD 解析、刷新恢复、实际开始面试、自我介绍、项目关联与提示；独立报告页已实际显示评分、未覆盖维度、训练计划和逐题回放，截图保存在本地忽略目录。

## 还未达到问镜完整能力的部分

- 当前导演为模型规划加规则预算，尚未移植问镜 Thompson Sampling、策略奖励、经验提取和聚合。
- 正式面试已接入 ES 混合检索，真实 DashScope 向量链路通过；目前是固定 BM25＋向量融合流程，还没有自主检索工具选择、查询改写和反复检索决策，不称为完整 Agentic RAG。
- 验证目前是规则验证，尚未完成问镜独立语义复核和完整多轮分数采用策略。
- 模型生成合同尚需人工审核题目元数据和质量基准；不能将本批合同作为人工评分真值。
- 知识来源仍要求选择一个已有题库；全量增量同步、可选多来源和删除传播待接入。
- 后端解析任务持久化，设置草稿目前在浏览器按用户保存；跨设备草稿、服务端草稿编辑与目录分组仍待补齐。
- 会话删除、用户反馈、诊断轨迹、独立快照/分页回放接口及长期能力档案待补齐。
- BYOK、匿名认领、额度运营、语音/视频及完整上游页面运行基线仍待核实和适配。

## 本轮 ES 混合检索接入

- 使用 DashScope OpenAI 兼容 `/embeddings`，模型 `text-embedding-v3`、1024维；Key仅写入被Git忽略的本地配置，和DeepSeek Key独立。
- ES 7.17 使用 `dense_vector + script_score`，BM25与向量独立召回后RRF融合；新增独立AI索引，不更改原题库业务索引。
- 题目快照按内容、来源版本、模型及维度生成缓存ID；首次按10条批量向量化，后续复用ES缓存。用于Embedding的每题文本最多6000字符，ES保存完整题目和参考答案；尚未实现长文分块。
- 两种召回都按本场未使用的快照文档过滤，避免混用其他题库或新旧版本。参考知识与召回轨迹保留在私有检查点，不暴露到待答页面。
- ES或Embedding失败明确标失败，支持显式重试，不自动重试付费请求，也不伪造向量。首轮同步总预算180秒，可能比缓存命中的后续轮次慢。
- 真实链路：Java → Nacos/OpenFeign → Python → DashScope/ES → DeepSeek → MySQL；已读回两轮混合召回轨迹、来源版本和ES文档真实1024维向量。
- 本轮发现并修复ES 7.17 `_mget`的`_source`参数兼容问题；集成测试与在线执行器争用锁后改用独立临时库，最终80项通过。
- 新一轮合成回答未被判为有效技术作答，报告没有强行给出综合能力分；此前浏览器完整作答报告已验证85分、维度覆盖和训练任务。上述验证证明链路与结构，不代表评分准确性和召回质量基准已建立。
- 清理本轮两个普通临时账号及三场所属测试面试、解析任务，浏览器恢复管理员；AI服务就绪并已注册Nacos。
