# JD 定向面试入口

## 用户流程

- 第一步明确选择“按岗位方向练习”或“针对招聘岗位面试”。方向练习沿用方向模板和简历，不要求真实 JD。
- 定向面试第三步粘贴真实招聘要求，或上传 PDF、DOCX、TXT、MD 文件（最大 5 MB）。文件只提取文本供核对，扫描 PDF 不做 OCR。
- 点击“解析岗位要求”，检查岗位技能、考察维度、解析依据和未映射要求。技能可修改，维度沿用原选择器。
- 勾选确认后才能开始。输入、岗位或级别改变会使旧结果失效；技能或维度改变必须重新确认。
- 原始招聘要求保存在 job_spec.description，随配置进入既有出题流程。工作流节点链路不变。

## 关键文件

- 前端 SetupForm.tsx：模式选择、文件上传、显式解析、结果核对和开始门禁。
- 前端 lib/jd-setup.ts：解析上下文身份与开始条件，防止旧 JD 结果用于新岗位。
- Python api/v1/interview.py：JD 文件安全提取，复用现有文件大小、格式与提取超时检查；JobSpecInput 增加 description。
- Java WenjingProxyController.java / WenjingRoutes.java：JD multipart 透传，沿用用户身份和内部服务认证。
- 同步脚本登记 API 类型和本地门禁适配，后续同步不覆盖。
